# code-secret
Code Secret : jeu de déduction de code coloré, installable (PWA)

Jeu de déduction de code coloré, jouable sur téléphone et ordinateur, installable (PWA, marche hors ligne).

**Jouer :** https://clementcarre-bionomeex.github.io/code-secret/

Réglages de difficulté : nombre de pions (3 à 6), nombre de couleurs (4 à 10), trou vide comme couleur, répétitions (unique, double, libre), indices groupés ou placés, nombre d'essais. Les lignes après la ligne à jouer servent de brouillon.

Pour l'installer : ouvrir l'adresse sur le téléphone puis « Ajouter à l'écran d'accueil » (ou l'icône d'installation dans la barre d'adresse sur ordinateur).
